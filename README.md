# 拾词 · Vocab Nest

我的专属生词记忆馆 —— 把记忆中遇到的生词，一组一组拾回来。

## 功能

- **以组为记忆单元**：每组 20 个生词，独立学习闭环（卡片 / 自测 / 列表三种模式）
- **每词八个板块**：释义、英美音标 + 点击发音、例句（可朗读）、用法、近形词辨析、近义词辨析、词组搭配、记忆口诀
- **生词本**：学习时一键标记，跨组收集，掌握后一键移出
- **进度记忆**：掌握 / 生词状态保存在浏览器本地（localStorage），换设备互不同步
- **深浅双主题**：跟随系统，可手动切换
- **双端适配**：手机（底部导航 + 滑动翻卡）与桌面（键盘 ←/→ 翻卡、空格朗读）
- **零依赖**：原生 HTML/CSS/JS，无框架、无外部请求，秒开不卡顿

## 词库怎么加

词库在 `js/data.js`，按组追加即可，页面自动读取，不需要改任何其他文件：

```js
{
  id: "g1",              // 只能用字母数字下划线连字符
  name: "第 1 组",
  words: [
    {
      word: "resilient",           // 必填，同组内不可重复
      phoneticUs: "rɪˈzɪliənt",   // 美音（不含方括号）
      phoneticUk: "rɪˈzɪliənt",   // 英音
      definition: "adj. 释义",
      examples: [{ en: "例句", zh: "翻译" }],
      usage: "用法说明",
      confusables: [{ word: "近形词", note: "辨析" }],
      synonyms: [{ word: "近义词", note: "辨析" }],
      collocations: ["搭配 翻译"],
      mnemonic: "记忆口诀"
    }
    // …每组 20 个
  ]
}
```

详细字段说明和数据契约见 `js/data.js` 顶部注释。

## 目录结构

```
vocab-site/
├── index.html      # 页面骨架 + 首帧主题脚本
├── css/style.css   # 响应式样式（深浅主题、移动优先）
└── js/
    ├── data.js     # 词库数据（加词只改这里）
    └── app.js      # 路由 / 卡片 / 发音 / 进度逻辑
```

## 本地预览

任意静态服务器均可，例如：

```
npx serve vocab-site
```

发音由浏览器内置 Web Speech API 提供（免费离线）；iOS 设备请关闭硬件静音开关。
