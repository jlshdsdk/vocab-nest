# 拾词 · Vocab Nest

我的专属生词记忆馆 —— 把记忆中遇到的生词，一组一组拾回来。

## 功能

- **以组为记忆单元**：每组 20 个生词，独立学习闭环（卡片 / 自测 / 列表三种模式）
- **每词八个板块**：释义、英美音标 + 点击发音、例句（可朗读）、用法、近形词辨析、近义词辨析、词组搭配、记忆口诀
- **生词本**：学习时一键标记，跨组收集，掌握后一键移出
- **跨设备进度同步**（2026-10-27）：设置页生成同步码，电脑/手机输入同一码即配对；开页自动拉取合并、标记后 5 秒自动推送、切后台立即推送。云端（textdb.online）只存进度不存词库，按词条时间戳取较新合并、永不丢记录；同步码即权限，只在自有设备间使用
- **数据备份**：设置页可导出/导入进度 JSON（与现有进度词粒度合并）
- **PWA 离线**：可添加到主屏幕，断网也能背词；部署更新时记得递增 sw.js 里的 CACHE 版本号
- **进度记忆**：掌握 / 生词状态保存在浏览器本地（localStorage），配合同步码跨设备
- **深浅双主题**：跟随系统，可手动切换（theme-color 随动）
- **双端适配**：手机（底部导航 + 滑动翻卡）与桌面（键盘 ←/→ 翻卡、空格朗读、顶栏导航）
- **零依赖**：原生 HTML/CSS/JS，无框架、无外部请求（仅同步时访问 textdb.online），秒开不卡顿

## 词库怎么加

词库在 `js/data.js`，按组追加即可，页面自动读取，不需要改任何其他文件：

```js
{
  id: "g1",              // 只能用字母数字下划线连字符
  name: "第 1 组",
  words: [
    {
      word: "resilient",           // 必填，同组内不可重复
      phoneticUs: "rɪˈzɪliənt",   // 美音（不含方括号）
      phoneticUk: "rɪˈzɪliənt",   // 英音
      definition: "adj. 释义",
      examples: [{ en: "例句", zh: "翻译" }],
      usage: "用法说明",
      confusables: [{ word: "近形词", note: "辨析" }],
      synonyms: [{ word: "近义词", note: "辨析" }],
      collocations: ["搭配 翻译"],
      mnemonic: "记忆口诀"
    }
    // …每组 20 个
  ]
}
```

详细字段说明和数据契约见 `js/data.js` 顶部注释。

## 目录结构

```
vocab-site/
├── index.html            # 页面骨架 + 首帧主题脚本
├── css/style.css         # 响应式样式（深浅主题、移动优先）
├── js/
│   ├── data.js           # 词库数据（加词只改这里）
│   └── app.js            # 路由 / 卡片 / 发音 / 进度 / 同步逻辑
├── sw.js                 # Service Worker（离线缓存，部署时递增 CACHE 版本）
├── manifest.webmanifest  # PWA 清单
└── icons/                # 应用图标（PWA / 主屏）
```

## 本地预览

任意静态服务器均可，例如：

```
npx serve vocab-site
```

发音由浏览器内置 Web Speech API 提供（免费离线）；iOS 设备请关闭硬件静音开关。
