# 拾词 · 月下藏书室

Selene’s Lexicon / Vocab Nest。以「月之暗面」与古希腊月神塞勒涅为意象的个人词汇学习站，移动端优先。纯 HTML / CSS / JavaScript，GitHub Pages 直接部署，无框架、无构建步骤。

## 学习与收藏

2026-11-05 手机体验修复：标记只局部更新，保留焦点、滚动与展开状态；切词不再整卡淡入/横移，底部可直接切词和标记。词组空闲期预备语音，优先同口音本地音色，重复的待播放点击不重启队列。近形/近义辨析分别显示双方释义与辨析说明，补充数据按组加载，来源及 MIT 许可见 data/README.md。

- 词组卡片、列表和混合自测；自测支持英→义四选一、义→英拼写、例句挖空。拼写容忍大小写和连字符差异，错误字母逐个提示；无可用例句时切换可用题型，不编造例句。
- 今日复习汇集到期词、生词与未完成的错词重练。三档自评为「认识 / 模糊 / 忘了」；错词连续答对两次才离开队列，刷新后仍保留重练状态。
- **每条近形词、近义词辨析都能单独收藏。** 生词本分为「生词 / 近形辨析 / 近义辨析」，保留源词、关联词、辨析说明和所属词组。同一个关联词出现在不同原词下时，不合并掉上下文。
- 生词本可按组、时间筛选排序，批量掌握或取消辨析收藏，导出 CSV / JSON。单词的「掌握并移出」会保留已掌握状态；取消辨析收藏保留带时间戳的取消记录，防止旧同步数据恢复它。
- 每日目标默认 20，可修改。每日词数按词条键（词组 ID + 单词）去重；单纯浏览不计入学习。热力图、连续学习天数和曲线来自真实操作日志，不用当前掌握状态编造过去的打卡。
- 月相表示实际掌握进度；月黑 / 月白双主题、本地英文字体、三档阅读字号、衬线 / 无衬线切换、减少动态效果支持。
- 英美音和例句朗读使用 Web Speech API，保持首次点击的同步手势调用。实际音色依赖设备语音库；iPhone 无声时请检查静音开关及系统英语语音。

## 本地预览

在站点目录运行：

~~~powershell
python -m http.server 8766 --bind 127.0.0.1
~~~

打开 http://127.0.0.1:8766/ 。不要直接以 file:// 打开页面；按组 JSON 和 PWA 需要 HTTP。

手机底栏：词组、复习、生词、足迹；设置在顶栏。桌面学习快捷键：左右切词、空格回忆 / 下一题、S 发音、1/2/3 自评、Esc 返回。输入框、中文输入法组词和浏览器组合键不被快捷键劫持。

## 词库维护：源文件不变，JSON 是机械生成物

唯一完整来源仍是 [js/data.js](js/data.js) 的 GROUPS。字段保留：word、phoneticUs、phoneticUk、definition、examples、usage、confusables、synonyms、collocations、mnemonic；组记录保留 id、name、note、words。

- 组 ID 仅用字母、数字、下划线、连字符；同组内 word 不能重复。
- 辨析条目继续采用 { word, note }；收藏元数据另存，不改词库。
- 添加或修改词条后运行维护命令，并提交生成结果：

~~~powershell
node tools/split-data.cjs
~~~

生成 data/manifest.json、data/groups/*.json 和 data/search-index.json。发布后的页面直接读取已提交 JSON，不需要服务器或部署时构建。首页只加载目录，词组按需获取，搜索索引首次搜索时加载；完整 js/data.js / window.GROUPS 继续作为兜底。

每次发布代码、样式或词库，都应递增 sw.js 的 CACHE 版本。新壳预缓存强制重新验证 HTTP 资源，避免把旧浏览器 HTTP 缓存混入新壳；完整词库不加入首次预缓存。

## 本地数据与跨设备同步

原有三个键保持兼容：

| 键 | 内容 |
| --- | --- |
| vocab-progress-v1 | 原有 gid:word → {s: hard/mastered, t: 时间戳} |
| vocab-prefs-v1 | 主题、字号、字体、目标和题型偏好 |
| vocab-sync-v1 | 原同步码及最近同步时间 |
| vocab-learning-v1 | 复习安排、错词状态、辨析收藏、取消标记时间和阅读位置 |
| vocab-activity-v1 | 真实学习事件日志 |

原云端协议和同步码格式不变，仍按词条时间取较新记录。新增复习、日志和收藏使用同步码派生的独立增强记录，旧客户端不会把新字段清掉；自动同步也先合并再推送。取消标记、取消收藏使用增量时间戳，较新的重新标记仍能正常生效。

同步码相当于访问权限，仅用于自己的设备，不公开、不写入下载备份。偏好保存在各设备；完整备份 v2 包含词汇状态、复习、收藏和日志，也兼容旧版裸进度与 v1 备份。导入始终先预览再合并，不清空已有数据。旧词库中暂未收录的记录仍保留展示与备份。

网络或同步服务失败不阻塞本地学习；设置页会明确显示原进度或增强记录是否同步完成。云服务为 textdb.online，应用不缓存其请求。

## 离线与更新

可添加到主屏幕。应用壳与目录预缓存，已访问的词组、字体和插画按成功请求缓存；未访问的组离线时会给出重试入口，联网后继续。更新不会强制打断正在输入的答案。缓存清理只针对 vocab-nest 命名空间，不删除同域其他项目缓存。

## 开发验证

算法和数据测试使用 Node 内置测试运行器。浏览器测试驱动真实 Chromium，需要本机安装 agent-browser；可通过 AGENT_BROWSER_CLI 指定其 JS 启动器或原生可执行文件。

~~~powershell
node --test --test-reporter=spec tests/*.test.cjs
~~~

测试包括原字段逐词等价、旧进度/备份迁移、真实旧 Service Worker 升级、离线访问、复习间隔、三种题型、22 次错词闭环、辨析收藏上下文、取消同步防恢复、字号/主题、360/390/430px 和桌面布局、减少动态效果与首次语音手势。不会使用真实用户同步码写入云端。

字体与插画来源见 [assets/README.md](assets/README.md)，实施与验收记录见 docs/superpowers/。Lighthouse 属于临时验证工具，不是站点依赖。
