# Visual assets

- `art/selene-moon.webp`: 1200×800, generated with the user's approved Selene concept through remote-imagegen (`gpt-image-2.5-sunburst`), then compressed to WebP. The uncompressed source and provider response stay outside the deployed repository.
- `fonts/`: Fontsource 5.3.0 WOFF2 files for Cinzel, Cormorant Garamond and Noto Serif. Corresponding SIL Open Font License texts are included. English display, body/italic and phonetic roles load independently with `font-display: swap`.
- Application icons are raster exports of the code-native `icons/moon.svg`; the maskable variant has a padded safe area. They are not crops of the artwork or fake interface screenshots.

Decoration is limited to the home cover. Word definitions, comparisons, questions and statistics are real HTML/SVG, never text baked into generated imagery.
