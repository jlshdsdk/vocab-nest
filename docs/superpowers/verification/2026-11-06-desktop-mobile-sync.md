# 电脑与手机收藏显示 / 同步修复

## 截图能证明什么

用户截图中，正式新版已加载，生词 / 近形 / 近义三类均为 0，筛选为全部。它说明当前电脑浏览器未显示收藏，但不能证明手机数据被删除，也不能判断是否使用同一个同步码。普通网址或 release 参数不会跨设备复制本地存储。

未直接访问截图中的实际 Edge 用户会话或真实手机；没有从截图猜同步码，没有读取其他站点 Cookie，也没有使用用户真实云记录做写测试。

## 核实与修复

- 原页面对未配对、同步等待、失败和真正空记录没有区分。生词本新增真实来源 / 状态面板和配对 / 导入 / 重试入口；失败时不再用普通空列表表示“没有收藏”。
- 首次同步在应用准备后及时开始。云端到达时，即使筛选器有焦点，收藏数量和列表也刷新，同时恢复焦点与滚动。
- 绑定已有同步码先读取验证，不存在或读取失败不替换原配对、不创建空记录。进度与增强收藏按各自格式检查；不允许用可读的辅助记录掩盖不兼容或读失败的主记录。
- 同源另一标签页的收藏 / 配对变化可刷新当前页。配对控件单独更新，保留未提交的备份输入，不出现“显示旧码、实际复制新码”。
- 返回前台可重新拉取另一设备变化。设置页保留当前失败 / 部分同步状态；进度时间与完整同步时间分开记录。
- 生词 30 条分页、辨析 15 条、折叠、导出与原本数据键 / 同步协议不变。

## 验证方式

两个彼此隔离的真实浏览器使用独立 localStorage，云端网络边界映射到本地内存 KV；执行手机标记及两类收藏→生成同步码→电脑验证配对→完整显示→手机新增→电脑过滤器仍聚焦时收取→网络失败重试→辅助收藏失败显示部分同步→电脑新增→手机刷新后保留。

测试云请求使用唯一 URL 防止 Service Worker 缓存测试替身；生产云 API 始终跨源，不受该替身影响。没有把两个共用 localStorage 的标签页冒充跨设备；另有真正同源双标签页测试用于验证 storage 事件。

独立审查指出两项配对边界和一项设置状态不一致，均新增对应失败用例后修复，不请求重复审查。真实用户配对状态和数据恢复、生产网络可用性以及所有并发多设备写入排列不属于本次受控证据可保证的范围。

审查修复证据：主记录不兼容 / 主读取失败但辅助可读的两项单元用例先失败后通过；跨标签页生成 / 更换配对时设置控件刷新，未提交备份文本不丢。再次进入设置仍显示已知失败 / 部分同步状态；完整同步时间独立于仅进度同步。

测试环境边界也单独核验：浏览器工具的初始脚本不自动延伸到新标签页，测试站点现在在所有测试 HTML 中先注入同一云边界，且阻止任何未代理的 textdb.online 请求。修正后的双标签页流程通过，不能把未隔离的测试替身结果用于声称生产云已验证。

## 用户需要完成的配对

在已有收藏的手机设置中复制原同步码并完成同步，再在电脑设置输入同一码配对；没有同步码时先在有数据的手机生成。不要在空电脑重新生成一个不同的码期待它读取原记录。网络不通可导出手机完整备份，在电脑预览后合并导入。不要清除网站数据。
