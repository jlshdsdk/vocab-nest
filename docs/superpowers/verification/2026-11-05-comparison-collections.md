# 辨析收藏折叠与每页 15 条

范围：仅近形、近义辨析收藏列表；原词库、释义、进度和同步身份键保持不变。普通生词页沿用原展示，不顺带改动。

## 行为

- 两类辨析收藏的每条记录使用原生 details / summary，默认收起；展开后显示双方释义、辨析、发音、回看原词和取消收藏。
- 复选框在折叠标题外独立操作，不因选择条目误开合；同一次访问中保留已展开条目的状态。
- 固定每页 15 条，页首/页尾都有上一页、下一页及页码选择，显示当前条目范围和总数。
- 近形/近义类别各自记住当前页；筛选、排序重置到第一页。翻页清掉隐藏页的批量选择，避免误取消。
- 末页不足 15 条正常显示；取消最后一条后自动回到有效页。翻页回到列表起点并保留键盘焦点。
- CSV / JSON 导出仍针对当前类别全部筛选结果，不局限于当前页。
