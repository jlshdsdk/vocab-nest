## 实施取舍

- 在原仓库本地排除规则中忽略 worktree，业务代码与 main 历史不变；另一份克隆需自行保留忽略规则。
- 无 Git Bash 时，以 PowerShell / Node 保持相同的计划、提交范围与 ledger 格式；额外成本是人工核对记录。
- 先实现复习 / 统计纯算法再接 UI，避免临时数据；提交顺序因此与文件级方案不同。
- 错词完成和取消收藏保留带时间戳的 inactive 记录；每个练习过的词会保留少量状态。
- 首页每次展开 12 组；全部 134 组和全库搜索可用，代价是后续词组多一次展开操作。
- 同步逻辑独立为 js/sync.js，便于实测在途合并；代价是多一个小型脚本请求。
- 自动推送前先读合并，以保留另一设备的新增收藏；代价是每次批量同步多出读取请求。
- 离开自测后回到卡片，而不重建已取消的临时题目；已答进度与错词记录保留，代价是需要重新进入自测界面。
