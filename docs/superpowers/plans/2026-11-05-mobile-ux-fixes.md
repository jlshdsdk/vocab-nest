# 手机学习体验修复

用户请求：修复音标发音延迟、近形/近义辨析缺双方释义、切词与标记抖动；以实际客户路径连续测试，发现不适后再修一轮。继续在现有隔离分支原生实施，不改变词库含义、旧进度和同步码。

## 验收目标

1. 标记状态仅局部更新，不替换卡片、按钮、焦点或 details 展开状态；滚动偏移不漂移。切词不播放淡入/横移动画，不盲目 scrollIntoView；底部常用操作在手机上始终可达。
2. 语音不在用户点下发音时冷启动选音色。预备本地音色、同步保留首次用户手势；快速重复点击不积压播放队列，立即显示播放/准备/错误状态，切词停止前词音频。
3. 13,099 条近形/近义关联显示原词、关联词各自释义与独立辨析说明，生词本、导出和既有收藏也可看到双方释义。优先本站原词库，其余用许可允许的 ECDICT 数据补充；明确记录来源，不把辨析说明冒充词典释义，不编造缺词。
4. localStorage 仍同步保存最新数据，但不在每个翻词动作重写整个学习日志；不因后台同步替换正在阅读的卡片。
5. 真实浏览器测量滚动、DOM 稳定、首次语音调用和重复播放，连续执行学习→发音→标记→切词→收藏→自测→复习→刷新。覆盖 360/390/430px、长词、大字、浅色及减少动态效果。
6. 完成第一轮修复后，再以黑盒客户操作复测。记录真实发现，不把自动化计数当作无 bug 保证；实际手机语音硬件和系统键盘限制如实说明。
7. 所有修复先复现 RED，再转 GREEN；全套回归、差异核验后更新原站，验证旧缓存/用户数据保留。
