## 已核实

- 收藏和进度按浏览器本地保存；版本 query 参数不改变同源 localStorage，也不负责跨设备配对。
- 当前 UI 对未配对、首次同步等待、网络失败和真正空记录展示相同空列表。
- 原同步合并回调在 select / input 有焦点时跳过重绘；过滤器仍有焦点时云端已载入的数据可未显示。
- 手动绑定只验证字符串格式；拼错但合法的码会初始化一个空云记录，容易让人以为原收藏消失。
- 未直接访问截图中的 Edge 用户会话，不读取其他网站凭据，不声称已确认用户配对状态。
